# Changelog

All notable changes to the NDI Webcam App will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-11-11

### Added
- Initial release of NDI Webcam App
- Multi-camera support (front, back, wide, telephoto)
- Real-time camera preview
- Streaming quality selection with presets:
  - 4K 30fps (Max Quality)
  - 4K (Ultra High)
  - 1080p 60fps (Very High)
  - 1080p 30fps (High)
  - 720p (Medium)
  - 480p (Low)
- Start/Stop streaming controls
- Camera permission handling
- Microphone permission handling
- NDI service layer architecture
- Visual streaming indicator (LIVE badge)
- Cross-platform support (Android & iOS)
- Comprehensive documentation
  - README.md with usage instructions
  - DEVELOPMENT.md with technical details
  - LICENSE file (MIT)

### Technical Features
- Flutter 3.0+ compatibility
